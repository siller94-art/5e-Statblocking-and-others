# Statblock 5e

Foundry VTT v14 module for importing D&D 5e monsters/NPCs, species, classes, and subclasses from pasted text or text-based PDFs.

## Installation

Manifest URL:
`https://raw.githubusercontent.com/siller94-art/5e-Statblocking-and-others/main/module.json`

Manual ZIP: extract the `statblock-5e` folder into `Data/modules/`.

## Features

- Import monster/NPC statblocks into NPC Actors.
- Import species/race, class, and subclass text into D&D5e Items.
- Auto-detect or manually choose content type.
- Load PDF, TXT, MD, and JSON files.
- No build step or external runtime dependency.

PDF note: scanned/image-only PDFs need OCR before importing because they do not contain selectable text.

Targets Foundry VTT v14.359+ and D&D5e 6.0.0.
